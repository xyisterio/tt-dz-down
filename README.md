# tiktok-relay-bot

Приватный Telegram-бот: присылаешь ему ссылку на TikTok (или сразу видео)
либо ссылку/название трека Deezer, он скачивает файл и по кнопке
отправляет его в один из подключённых каналов от своего имени.

## Как пользоваться

1. Пиши боту `/start`.
2. Кинь ссылку на TikTok — бот скачает и предложит выбрать канал.
3. Или сразу перешли/пришли видеофайл — предложит выбрать канал сразу,
   без скачивания.
4. Кинь ссылку на трек Deezer (обычную или короткую share-ссылку) — бот
   скачает трек через свой dzmedia-сервер и предложит выбрать канал.
5. Или просто напиши название трека/исполнителя — бот поищет на Deezer
   и покажет варианты кнопками; после выбора — скачает и предложит канал.

Поддержка Deezer требует настроенных `DEEZER_API_URL` и `DEEZER_ARL`
(см. `.env.example`) — это отдельный Rust-сервер (dzmedia), который
получает реальные ссылки на аудио и расшифровывает их с помощью ARL-куки
залогиненного аккаунта Deezer. Без этих переменных бот продолжит работать
только с TikTok.

Качество треков Deezer (FLAC / MP3 320 / MP3 128, по умолчанию — 320
кбит/с) переключается прямо в Telegram командой `/quality`, выбор
сохраняется и переживает рестарт (если настроен Redis).

### Кто качает файл

Правило одинаковое для видео (TikTok) и аудио (Deezer):

- если файл укладывается в ~20 МБ — Telegram скачивает его сам по прямой
  ссылке (CDN TikTok или `/download` у dzmedia) — быстрее и не грузит бота;
- если файл больше (до 50 МБ — абсолютный лимит Bot API на загрузку) —
  качает и грузит в Telegram сам "сервер": для TikTok это сам этот бот
  (yt-dlp качает локально, потом отправляет файлом), для Deezer — это
  dzmedia через свой `/send_audio` (нужен свой `BOT_TOKEN` на его стороне);
  если он недоступен — бот подстрахуется и скачает трек сам.

## Как подключить канал

Один из двух способов, оба работают сразу, без ожидания нового поста:

- добавь бота **администратором** канала — он сам зарегистрируется по
  системному апдейту о смене роли;
- либо перешли боту в личку **любое, даже старое** сообщение из этого
  канала — он прочитает, откуда оно, и запомнит канал.

Отправлять в канал бот всё равно сможет только если он там админ — это
ограничение самого Telegram Bot API, ничем не обходится.

`/channels` — посмотреть список известных каналов.

## Деплой на Render

1. Залей эту папку в свой GitHub-репозиторий.
2. На Render: **New → Blueprint**, укажи репозиторий — подхватит
   `render.yaml` автоматически.
3. Тип сервиса в `render.yaml` — `web`, а не `worker`: у Render просто нет
   бесплатного плана для Background Worker (только Web Service, Static
   Site, Postgres и Redis). Поэтому бот сам поднимает внутри процесса
   крошечный HTTP-сервер на `$PORT`, который только отвечает "ok" —
   это нужно исключительно чтобы Render увидел открытый порт и не писал
   в логи "No open ports detected". На саму работу бота (long polling,
   без вебхука) это не влияет.
4. Бесплатный Web Service на Render "засыпает" после ~15 минут без
   HTTP-запросов и потом отвечает на них с задержкой в холодный старт —
   но long polling к боту это не касается, спать он не будет, пока сам
   процесс жив. Если Render всё же остановит инстанс из-за неактивности,
   можно раз в несколько минут дёргать его health-check URL (например,
   через UptimeRobot / cron-job.org), чтобы он не засыпал.
5. В настройках сервиса задай переменные окружения:
   - `BOT_TOKEN` — токен от @BotFather;
   - `OWNER_ID` — твой числовой Telegram id;
   - `UPSTASH_REDIS_REST_URL` / `UPSTASH_REDIS_REST_TOKEN` —
     необязательно, но без них список каналов не переживёт рестарт
     контейнера (бесплатный план Render перезапускает инстансы);
   - `DEEZER_API_URL` / `DEEZER_ARL` (+ опционально `DEEZER_FORMAT`,
     `DEEZER_SEND_AUDIO_TIMEOUT_MS`) — для поддержки Deezer; без них бот
     работает только с TikTok.
6. Деплой соберёт Docker-образ с Node.js + `yt-dlp` + `ffmpeg` и запустит
   бота через long polling — вебхук не нужен.

## Ограничения

- Загрузка файлом через Bot API ограничена **50 МБ** — если ролик
  тяжелее, бот сообщит об этом и не станет отправлять.
- `yt-dlp` иногда не может скачать приватные/возрастные/удалённые
  ролики — TikTok меняет защиту без предупреждения, при сбоях бот
  пришлёт текст ошибки как есть.
- Скачивание Deezer-треков ограничено тем же лимитом в 50 МБ — длинные
  FLAC-треки иногда в него не влезают, тогда лучше `DEEZER_FORMAT=MP3_320`.
- Deezer зависит от валидности ARL-куки: она привязана к сессии аккаунта
  и может протухнуть — тогда dzmedia-сервер начнёт отвечать ошибкой и куку
  нужно будет обновить.
